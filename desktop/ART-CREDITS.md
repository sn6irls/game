# 에셋 기록

캐릭터 동작 시트, 거대 얼굴·눈, 게임 아이콘, 광고, 도구 이미지는 사용자가 제공한 이미지의 웹 최적화본입니다.
봇 시트는 4×3칸이며 서 있는 5번째 칸을 바탕화면 아이콘으로 사용합니다.
젤리는 사용자의 jelly.blend에서 내보낸 5종 모델을 사용하며, 분홍 젤리는 착지 방향이 다른 형태도 있습니다.
XP 배경·아이콘의 출처는 assets/XP-ICONS-SOURCE.txt를 참고하세요. 휴지통 잡동사니는 사용자 제공 XP 아이콘 시트에서 추출했습니다.
스티커 21개와 노란 눈동자 도구 아이콘은 사용자 제공 stickers.png에서 개별 분리한 WebP입니다.
