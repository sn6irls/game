# 슈퍼짱의 가챠뽑기

[게임 시작](https://sn6irls.github.io/game/gacha/)

동전을 누르고 손잡이를 한 바퀴 돌려 캡슐을 뽑는 3D 가챠 게임입니다. PC 마우스와 모바일 터치로 플레이할 수 있습니다.

- 캡슐을 돌려 보고 눌러 열기, 손 위 경품 회전, 바닥 캡슐 굴리기
- 쓰레기·평범·슈퍼레어 경품과 결과에 따른 표정·대사
- 뽑기 횟수와 가상 사용 금액 표시, 경품 목록, 한국어·영어 전환
- 이미지·GLB로 SSR 교체, SSR 획득 화면 사진 저장

1회 가상 금액은 4,000원입니다. 실제 결제는 없습니다. 확률은 N 77.3%, R 18%, SR 3.7%, SSR 1%이며, SSR 없이 29번 뽑으면 30번째에는 SSR이 나옵니다. 새로고침하면 기록과 교체한 경품이 초기화됩니다.

별도 빌드 없이 정적 웹 서버에서 실행합니다. 진입점은 `index.html`과 `authored-play.js`입니다.

Three.js 및 Neo둥근모 글꼴의 라이선스는 각각 `vendor/three/LICENSE`, `asset/OFL-NeoDunggeunmo.txt`에 포함되어 있습니다.
